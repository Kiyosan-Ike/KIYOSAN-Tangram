# KIYOSAN-Tangram

KIYOSAN-Tangramは、7つのピースを動かし、回転・裏返しをしながら形を作る、学習用のタングラムWebアプリです。
Mac、iPad、iPhoneなどのWebブラウザで使用できます。

現在のバージョン：Ver.2.1

## Ver.2.1（操作性完成版）

Ver.2.0を基礎に、操作性、表示、ヒント、端末対応を仕上げました。

- 「シルエットの上で作る」と「完成図を見ながら作る」の2つの遊び方
- ピースの移動、45度回転、平行四辺形の裏返しを調整
- シルエット上では正しい位置に重なった場合だけ完成と判定
- 完成図を見ながら作る場合は、盤面のどこで作っても外形が正しければ完成と判定
- 段階的ヒントを、ピースごとの実線表示から色表示へ進む方式に変更
- 教師モードに1ピースヒントを用意
- 「ひとつ前に戻す」操作を追加
- 初回だけ表示される簡単な操作案内を追加
- 「かたづける」で正方形へ戻す終了演出を追加
- カラフル、木目調、写真の3種類のピースデザイン
- 選んだ写真を端末内に保存し、次回も利用可能
- BGMと効果音のオン・オフ、完成音、レベル全問クリア演出
- 漢字表記とひらがな表記の切り替え
- iPhone、iPad、Macでのレイアウトと操作性を改善
- iPad縦画面、iPhone縦画面、全画面表示を調整
- オフライン利用に対応した更新用キャッシュを改善

## 基本的な遊び方

1. 「問題」を押して、レベルと問題を選びます。
2. 「はじめる」を押すと、ピースが盤面に広がります。
3. ピースをドラッグして移動します。
4. ピースの角をドラッグするか、回転ボタンで45度ずつ回転します。
5. 平行四辺形は「裏返す」で反転できます。
6. 困ったときは「ヒント」を使います。
7. 形が完成すると、自動で完成を知らせます。

## 設定できること

- シルエットの上で作る／完成図を見ながら作る
- 問題と方眼の色
- カラフル／木目調／写真のピース
- ピースの大きさ
- BGMと効果音
- 漢字／ひらがな表記
- 教師モード
- 全画面表示

## Webへの設置

このアプリのファイル一式をHTTPS対応のWebサーバーへアップロードしてください。
GitHub Pagesでも公開できます。

PWAのインストールとオフライン機能は、file://でindex.htmlを直接開いた場合には動作しません。
HTTPS対応のWebサーバー上で使用してください。

## iPad・iPhoneのホーム画面への追加

1. Safariで公開したKIYOSAN-Tangramを開きます。
2. 共有ボタンを押します。
3. 「ホーム画面に追加」を選びます。
4. ホーム画面のアイコンから起動します。
